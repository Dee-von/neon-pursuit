FREE HOSTING (GitHub Pages)
1. Create a free account at github.com and a new public repository named neon-pursuit.
2. Upload ALL files from this folder (including .nojekyll) to the repository root.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. In 1-2 minutes your game is live at https://YOURUSERNAME.github.io/neon-pursuit/
5. On Android Chrome: open the link, menu (3 dots) > "Add to Home screen" / "Install app". It opens full screen and works offline.
Alternative: drag this folder onto https://app.netlify.com/drop for an instant free link.
